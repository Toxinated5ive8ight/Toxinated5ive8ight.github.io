FREE HOSTING OPTION: GITHUB PAGES
1. Create/sign in to a GitHub account.
2. Create a new public repository, for example "techpulse".
3. Upload the contents of this folder (not the outer folder itself) to the repository's main branch.
4. In repository Settings → Pages, choose deploy from the main branch and the root folder.
5. Wait for GitHub Pages to publish, then open the URL shown in Settings → Pages.
